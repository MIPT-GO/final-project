## Booking Service

### Get All Reservations For Email
Request:
```
GET /v1/booking/email/{email: str}/
```
Status Codes:
```
200 OK
```

```
500 Internal Service Error
```

Response Body:
```json
{
   "reservations": [
    {
        "email": string,
        "start": date,
        "end": date,
        "hotel": string,
        "number": int
    }
   ]
}
```

## Payment System
### Create Pay Link
```
POST /v1/payment/link/
```
Request Body:
```json
{
   "amount": string,
   "webhook": string,
   "message": string
}
```
Status Codes:
```
200 OK
```

```
500 Internal Service Error
```
Response Body:
```json
{
   "link": url-string,
}
```

**Note**: on the webhook address will be send this request:
```
POST webhook
```
Request Body:
```json
{
   "status": string
}
```

If the user has paid for the service, status is `ok`
If the user has not paid for the service within a fixed period of time, status is `timeout`

## Notification Service

### Kafka topic

Booking Svc отправляет события в Kafka в топик `notifications`.

Каждое сообщение должно содержать:

- **key**: `send_notification`  
- **headers**:
  - `format: json`
- **value**: JSON-объект с данными события бронирования

### Notification message (value)

Пример сообщения (value):

```json
{
  "event": "booking_created",
  "email": "client@example.com",
  "owner_email": "owner@example.com",
  "hotel": "Hilton",
  "number": 101,
  "start": "2025-12-15T12:00:00Z",
  "end": "2025-12-20T12:00:00Z"
}
```

Где:

- `event`: string — тип события:
  - `booking_created`
- `email`: string — email клиента (может быть пустым)
- `owner_email`: string — email владельца отеля (может быть пустым)
- `hotel`: string — название отеля
- `number`: int — номер комнаты
- `start`: string — дата/время начала (RFC3339)
- `end`: string — дата/время окончания (RFC3339)

Сервис Notification читает эти сообщения, формирует текст письма и отправляет email через внешний SMTP (Gmail).
